A make.fun entry for [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): the GPS's one-line excuse for sending the driver down the wrong road.

## The line

> According to my map, this lake is a road. According to the lake, it is not. I choose to believe the map.

The GPS, caught red-handed at the water's edge, stays loyal to the map over reality itself — smug, defensive, and blaming the map, exactly as charged.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18+ (runs `main.ts` as-is). The program writes the single line to `/output/entry.txt` (104 characters, UTF-8, within the 1–200 gate).
